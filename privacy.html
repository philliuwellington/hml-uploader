Privacy Policy

Last updated: 11 November 2026

HML Uploader ("the tool") is a private desktop tool. Its owner uses it to upload their own videos to their own YouTube and TikTok accounts.

What data the tool uses

  • Access tokens from Google (YouTube) and, if connected, TikTok, which the owner grants by signing in.
  • Basic channel information (channel name and ID) to show which account is connected.
  • The owner's own video files and the texts (title, description, hashtags) entered for them.

How the data is used and stored

  • The data is used only to upload the owner's videos and to check whether an upload has been processed.
  • Access tokens are stored only on the owner's computer, encrypted with Windows data protection (DPAPI) for the owner's user account.
  • No data is sent to any server operated by this tool. There is no database, no analytics and no advertising.
  • No data is sold, shared with or transferred to third parties, except to YouTube and TikTok themselves when uploading.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions (Google) or in the TikTok app settings. Deleting the tool's folder on the owner's computer removes all stored tokens.
